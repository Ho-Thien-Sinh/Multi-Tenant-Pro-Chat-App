# Frontend - Multi-Tenant Chat App

Frontend React cho ứng dụng Chat đa tenant.

## Cài đặt

```bash
npm install
```

## Chạy development

```bash
npm run dev
```

App sẽ chạy tại http://localhost:5173

## Build

```bash
npm run build
```

## Preview

```bash
npm run preview
```

## Tính năng

- Quản lý Tenants (khách hàng doanh nghiệp)
- Quản lý Users cho từng Tenant
- Chat real-time với Socket.io
- Giao diện hiện đại với TailwindCSS
